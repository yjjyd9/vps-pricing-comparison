従量制の効き方は使い方で変わる。1日だけ検証環境を立てる、夜間だけバッチを回す、といった使い方なら、月額固定の国内VPSより安く収まる。逆に24時間365日動かし続けるなら、$2.48/月のプランでも為替とカードの手数料込みで国内の格安プランと大きくは変わらない水準になる。安さが出るのは「使わない時間を止められる」ケースだ。

Vultrの公式クーポンページには4種類のオファーが並んでいる。

## 「月額◯円〜」を開けると数字が変わる

XServer VPSの公式ページは、月額1,265円〜のすぐ下に「XServer VPSは36ヶ月契約時、XServer VPSクラウドは12ヶ月契約時の月額です」と書いている。2GBなら月額1,265円、4GBなら2,035円、8GBなら3,850円。いずれも長期契約を前提にした税込価格で、月単位で契約した場合の金額は同じページに併記がない。

一方、2026年10月21日時点の比較記事の表には、XServer VPSが「990円〜」と書かれている。公式が1,265円と明記している以上、990円は別の条件（過去の価格、税抜表示、短期契約の割引など）としか考えられないが、その条件はどの資料にも書かれていない。990円で予算を組むと足りなくなる。

ConoHa VPSも同じ構図だ。公式の最低構成は512MBで460円/月（時間課金から38%OFF）、1GBで763円、2GBで1,259円/月。比較記事には「751円〜」と書かれているが、751円がどのプランを指すのかは公表されていない。2GBで比べるなら1,259円が実額になる。

だから比較のときは、自分の使う構成（多くの場合2GB）と契約期間を揃えて数字を並べる。「〜」の最安値は最安構成と最長契約の組み合わせで出ていることが多く、そこで差が出る。

## 性能の数字は、誰が測ったかを見る

XServer VPSの公式ページには「CPU処理性能が2位比 約3.7倍」「ランダムリードが約5.8倍」「ランダムライトが約1.7倍」という訴求がある。数値は3,506.32対946.77のように具体的で、測定条件（ブロックサイズ1MB、合計2GB、5分ごとに70回の平均）まで書かれている。

ただしこれは2024年11月18日付の自社調べで、比較相手はA社・B社・C社・D社と匿名だ。どのベンダーと比べたのか分からない以上、参考値として扱うのが妥当で、購入判断の主軸にはしないほうがいい。NVMe SSDとAMD EPYCを全プラン標準で載せている、国内データセンターで運用している、日本語サポートがある、という事実のほうが判断材料としては使いやすい。

## 用途で選ぶなら2GBか4GBか

XServerの案内は分かりやすい。個人利用やテストは2GB、開発と運用を兼ねるなら4GB、複数サービスを動かすなら8GB。これはベンダー自身の推奨なので、迷ったらこの線に乗せておけば外れにくい。

1台で足りるか、WEBとDBを分けるかで金額は倍以上変わる。ConoHa VPSの公式サイトの見積り例では、WEB 2GB×2台で2,518円、DB 2GB×2台で2,518円、ロードバランサー1,100円、データ転送は0円（無制限）という構成が紹介されている。同じ2GBプランでも、4台並べれば月5,000円超え。1台で済むのか、役割を分けるのかを先に決めたほうがいい。

- **個人開発・検証**：2GB／3コアで足りる。XServer VPSの2GBはvCPU 3コア、NVMe SSD 50GB。
- **WordPress**：KUSANAGI系のイメージを使うなら1GB以上が必須。512MBでは選択できない。
- **Webアプリの本番**：4GB以上＋バックアップの有無を確認。XServer VPSの4GBはvCPU 4コア、NVMe SSD 150GB。
- **ゲームサーバー**：XServerはARK、Nextcloudなどのアプリイメージを追加している。ABLENET VPSはMinecraft向けのイメージを持つ。
- **メールサーバー**：XServerの用途例に含まれる。ただしVPSはレンタルサーバーと違い、root権限で自分で設定する前提になる。

## 小さいプランで「できないこと」

ここが比較記事で落ちやすい。ConoHa VPSの公式テンプレートページには、プランごとの制限が注記として書かれている。

- 512MBプランでは**Ubuntuが使えない**（1GB以上での利用を推奨）
- 512MBプランでは**かんたんKUSANAGI、MIRACLE ZBXが使えない**
- **GitLabのテンプレートは512MB・1GB・2GBプランで使えない**（4GB以上が必要）
- WordPress(KUSANAGI)は新規作成時がAlmaLinux 9版で、再構築するとCentOS Stream 9版を選べる

バックアップの扱いもベンダーで違う。XServer VPSの標準プランは自動バックアップ欄が「—」で、クラウドの方だけが日次。ConoHa VPSの自動バックアップは有料オプションに分類されている。ロードバランサーも同じで、ConoHaのDSR方式は1,100円/月。データ転送が無制限0円なのは両社とも共通なので、そこは差がつかない。

最低利用期間は資料で食い違う。ConoHaの料金ページには「最低利用期間 無し」、第三者の比較記事には「1時間」とある。時間単価（24.2円/時など）が表示されている以上、時間単位の課金であることは間違いなく、1時間未満で削除した場合の扱いは申し込み前に確認したい。

## 最後に：3つの質問で決める

**契約期間を縛られたくないか。** 縛られたくないならVultrの時間課金。1時間で消しても1ヶ月動かしても単価は同じで、予約割引を使うかどうかは後から決められる。

**国内データセンターと日本語サポートが要るか。** 要るならXServer VPSかConoHa VPS。2GBで月1,265円と1,259円なので、このクラスでは実質同価格帯。違いはバックアップの標準有無と、512MBまで落としたときの制限の多さに出る。

**いきなり本番を置くか。** 置くなら4GB以上、バックアップは有料オプションの有無を確認、WEBとDBを分けるならロードバランサーの1,100円も見積りに入れる。触って試すだけなら2GBで十分。

申し込む前に確認するのは2つ。表示価格が何ヶ月契約の条件か、そしてバックアップが標準か有料か。この2点だけで、同じ「月額1,259円」でも1年後の支払総額は変わってくる。
